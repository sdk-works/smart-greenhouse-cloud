# 2026-09-05 点位配置闭环版本说明

版本：Point Workflow V1.0

## 新增

- 工控机发现模式：接收导航 `arrNN|`，只登记并可靠上报编号。
- 云端采集点配置页：查看发现次数、分配大棚与名称、设置时长和采集开关。
- 全量配置发布：发现/正式两种模式、递增版本、SHA-256 完整性校验、MQTT 保留消息。
- 工控机后台 DTU 下行监听、配置原子替换和历史配置备份。
- 点位发现及配置确认 SQLite 断点续传。
- 正式模式未知点保护：只报告、不采集。
- 管理后台手机适配：窄屏抽屉导航、点位卡片列表、全宽发布按钮和不溢出的配置弹窗。

## 数据库

新增 `nav_point_discoveries`、`robot_point_configs`、`robot_point_config_releases` 三张表；迁移不修改原表和原有业务数据。

## 已验证

- 云端后端编译、前端生产构建、HTTP 页面和健康检查通过。
- 云端发布 V1 发现配置，工控机校验并落盘，云端收到 `applied` 回执。
- 工控机 SQLite 事件经 COM1/DTU/MQTT 到达云端数据库，收到提交确认后清空待传队列。
- 云端及工控机 systemd 服务均为 enabled、active；传感器、相机、导航串口初始化正常，心跳持续确认。

## 当前运行状态

工控机当前为 `ROB001 / config_version=1 / discovery`。现场打点时不会执行土壤采集或拍照；后台分配完点位并发布正式模式后才开始采集。
