# 智慧大棚环境控制 V1.0 版本说明

发布日期：2026-08-25  
版本定位：云端软件基础版（尚未完成现场执行器联调）

## 本版新增

- 新增风机、水阀控制中心及最近命令记录。
- 新增执行器档案：控制模式、区域、期望状态、实际状态、安全限制、维护锁、急停状态。
- 控制命令采用“先入库、再发布、等回执”流程，状态包括 pending、sent、accepted、executing、executed、rejected、failed 等。
- 新增动作白名单、最长运行时间、维护/急停只允许关闭等服务端校验。
- 新增“一键紧急关闭全部水阀”，每台水阀生成独立、可审计的关闭命令。
- 新增控制规则保存与校验接口；V1 强制以禁用状态保存，不自动执行。
- MQTT 新增 `agri/device/{device_id}` 命名空间与设备回执处理。
- 补齐控制权限及关键操作审计日志。

## 同步修复

- 修复旧设备命令接口调用 MQTT 参数数量不一致的问题。
- 统一环境执行器的命令/上行 Topic，避免与巡检机器人消息混用。

## 当前边界

- 本版不是现场验收版。未接入真实风机、水阀控制器，不能把 `sent` 当成动作成功。
- 只有收到相同 `command_id` 的设备回执并进入 `executed`，云端才认为动作完成。
- 自动控制执行器、传感器异常判定、联锁矩阵及断网本地自治留到 V1.1 现场联调后启用。
