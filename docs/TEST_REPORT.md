## 五、问题清单

### 🔴 严重问题（已修复）
1. MQTT 消息迭代方式错误 → `async for msg in client.messages` 修复
2. Python 3.10 不支持 Z 时间戳 → `.replace("Z", "+00:00")` 修复
3. 新增设备后 MQTT 无法接收 → 动态订阅机制修复
4. bulk update() 缓存问题 → ORM 对象赋值修复
5. 图片上传权限 → mkdir + chmod 修复

### 🟡 一般问题（已修复）
6. CORS 列表解析 → field_validator 修复
7. WebSocket 并发广播 → asyncio.Lock 修复
8. Redis listener 变量 NameError → 初始化为 None 修复
9. Dashboard N+1 查询 → GROUP BY 批量查询修复
10. timestamp 时区不一致 → 全链路 UTC 统一

### 🟢 优化建议（已实现）
11. 首页 Landing Page 炫酷展示 ✅
12. 系统配置中心（MQTT/大棚/机器人） ✅
13. 图片管理独立页面 ✅
14. 设备注册返回 MQTT topic 信息 ✅
15. 告警阈值可配置 ✅
