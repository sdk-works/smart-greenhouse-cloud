    React 前端 (Nginx :80)

## 三、MQTT 协议规范

### 3.1 Topic 格式

| 方向 | Topic 格式 | QoS | 说明 |
|------|-----------|-----|------|
| 上行（遥测） | `agri/{greenhouse_id}/{device_id}/telemetry` | 0 | 主要数据通道 |
| 上行（旧格式兼容） | `agri/{device_id}/telemetry` | 0 | 无大棚ID时使用 |
| 下行（指令） | `agri/{greenhouse_id}/{device_id}/command` | 1 | 控制命令 |

> **注意 v8 变更**：已删除 status topic，心跳走 telemetry（type=heartbeat）

### 3.2 遥测数据格式

```json
{
  "device_id":    "robot_001",
  "greenhouse_id":"gh_xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
  "timestamp":    "2026-03-24T20:00:00Z",
  "type":         "telemetry",
  "data": {
    "temperature":   25.6,
    "humidity":      60.0,
    "co2":           800,
    "light":         12000,
    "soil_moisture": 45.0,
    "ph":            6.8
  },
  "robot_status": {
    "battery":  85.2,
    "speed":    0.5,
    "status":   "patrolling",
    "position": { "x": 30.5, "y": 15.2 }
  },
  "image": null
}
```

### 3.3 心跳格式（60s 发一次）

```json
{
  "type":      "heartbeat",
  "robot_id":  "robot_001",
  "timestamp": 1710000000,
  "battery":   78,
  "status":    "idle"
}
```

### 3.4 时间戳规范

```
机器人端：datetime.now(timezone.utc).strftime("%Y-%m-%dT%H:%M:%SZ")
后端解析：_parse_timestamp() → UTC datetime with tzinfo
数据库：  TIMESTAMPTZ（带时区）
前端显示：formatUTCtoLocal(ts) → 本地时间
```

### 5.2 4G/WiFi 分流策略

```python
# 机器人端伪代码
import subprocess

def get_network_type():
    """检测当前网络类型"""
    # 根据实际情况实现：检查网卡名称、IP地址范围等
    return "wifi"  # or "4g" / "ethernet"

def upload_or_cache(image_path, device_id):
    net = get_network_type()
    if net == "4g":
        # 本地缓存，不上传
        cache_queue.append(image_path)
    else:
        # WiFi/有线，立即上传
        upload_image(image_path, device_id, network_type=net)

def batch_upload_cache(device_id):
    """WiFi 连接时批量上传缓存"""
    if get_network_type() != "4g" and cache_queue:
        batch_upload(cache_queue, device_id)
        cache_queue.clear()
```

## 六、机器人端接入（Python示例）

```python
#!/usr/bin/env python3
"""robot_client.py - 机器人端 MQTT 接入示例"""
import json, time, paho.mqtt.client as mqtt
from datetime import datetime, timezone

BROKER   = "your_server_ip"
DEVICE   = "robot_001"
GH_ID    = "your_greenhouse_id"  # 从 GET /api/v1/devices/{id}/mqtt-topics 获取
PREFIX   = "agri"

client = mqtt.Client(client_id=DEVICE)
client.username_pw_set("admin", "public")
client.connect(BROKER, 1883)

def publish_telemetry(sensor_data, robot_status):
    topic   = f"{PREFIX}/{GH_ID}/{DEVICE}/telemetry"
    payload = {
        "device_id":    DEVICE,
        "greenhouse_id":GH_ID,
        "timestamp":    datetime.now(timezone.utc).strftime("%Y-%m-%dT%H:%M:%SZ"),
        "type":         "telemetry",
        "data":         sensor_data,
        "robot_status": robot_status,
    }
    client.publish(topic, json.dumps(payload), qos=0)

def publish_heartbeat():
    topic = f"{PREFIX}/{GH_ID}/{DEVICE}/telemetry"
    payload = {
        "type":      "heartbeat",
        "robot_id":  DEVICE,
        "timestamp": int(time.time()),
        "battery":   85,
        "status":    "idle",
    }
    client.publish(topic, json.dumps(payload), qos=0)

# 主循环
client.loop_start()
hb_timer = 0
while True:
    # 每10秒上报遥测
    publish_telemetry(
        sensor_data={"temperature":25.6,"humidity":60,"co2":800,"light":12000},
        robot_status={"battery":85,"speed":0.5,"status":"patrolling","position":{"x":30,"y":15}}
    )
    # 每60秒心跳
    if time.time() - hb_timer > 60:
        publish_heartbeat(); hb_timer = time.time()
    time.sleep(10)
```

## 九、常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| MQTT 消息不接收 | 设备未注册 | POST /api/v1/devices/ 注册设备 |
| 时间戳显示不对 | 时区问题 | 确保机器人端上报 Z 后缀 UTC 时间 |
| 图片上传失败 | 目录权限 | `sudo bash update.sh` 修复权限 |
| 注册后 MQTT 不订阅 | 服务未重连 | `sudo systemctl restart greenhouse` |
| 前端无实时数据 | WebSocket 断开 | 检查 Nginx ws 配置，确保 Upgrade 头 |
