# 智慧温室巡检机器人平台 v8 — 用户操作手册

---

## 快速上手（3步开始使用）

```
第1步：访问 http://服务器IP → 查看大屏展示
第2步：点击"进入管理平台" → 进入后台
第3步：创建大棚 → 注册机器人 → 开始工作
```

---

## 一、首页大屏

访问平台地址后，您将看到展会级大屏展示页面：

| 区域 | 内容 |
|------|------|
| 顶部 | 平台名称、实时时钟 |
| 左侧 | 温度/湿度/CO₂/土壤湿度实时仪表盘，AI病害识别框 |
| 中间 | 温室俯视地图，机器人实时位置和巡检轨迹 |
| 右侧 | 当前任务进度，系统状态 |
| 底部 | 大棚数/机器人数/今日巡检次数等统计 |

点击右上角 **"进入管理平台 →"** 按钮进入后台。

---

## 二、大棚管理

### 2.1 新建大棚

1. 点击左侧导航 **"大棚管理"**
2. 点击右上角 **"新建大棚"** 按钮
3. 填写信息：
   - **大棚名称**（必填）：如 `1号大棚·番茄区`
   - **位置**（选填）：如 `东区A-1`
   - **面积**（选填）：单位 m²
   - **作物类型**（选填）：从下拉菜单选择
   - **描述**（选填）：备注信息
4. 点击 **"创建"** 完成

### 2.2 编辑大棚

在大棚列表中，点击对应行的 **"编辑"** 按钮，修改后点击保存。

### 2.3 删除大棚

点击 **"删除"** 按钮，确认后删除（历史数据不会被删除）。

### 2.4 查看大棚详情和统计

点击 **"详情/点位"** 按钮，可查看：
- 基本信息和近1小时环境均值
- 点位管理（见下节）

---

## 三、大棚点位管理（新功能）

> 点位是机器人在大棚内的巡检停靠点，您可以配置机器人在每个点位执行什么动作。

### 3.1 打开点位管理

1. 在大棚列表点击 **"详情/点位"**
2. 切换到 **"📍 点位管理"** 标签页

### 3.2 添加点位

点击 **"添加点位"**，填写：
- **点位名称**（可选）：如 `A区1号采样点`
- **X坐标**（必填）：点位在大棚地图上的水平位置（0~100米）
- **Y坐标**（必填）：点位在大棚地图上的竖直位置（0~60米）
- **到达后执行的动作**（可多选）：
  - 📷 拍照
  - 🌡️ 测量环境
  - 🔍 病虫害检测
  - 🌱 土壤采样
- **备注**（可选）

点击 **"添加"** 保存。

### 3.3 编辑点位

在点位列表中点击 **"编辑"**，修改后保存。

### 3.4 删除点位

点击 **"删除"**，确认后删除该点位。

> 💡 **小贴士**：坐标系以大棚左上角为原点，X向右，Y向下。建议按巡检顺序添加点位。

---

## 四、机器人管理

### 4.1 注册新机器人

1. 点击左侧导航 **"机器人管理"**
2. 点击 **"注册机器人"**
3. 填写信息：
   - **机器人ID**（必填）：与机器人硬件配置保持一致，如 `robot_001`
   - **名称**（必填）：如 `1号巡检机器人`
   - **默认所属大棚**（选填）：从已创建的大棚中选择
   - **固件版本**（选填）：如 `v2.1.0`
4. 点击 **"注册"**

注册成功后，系统自动显示 **MQTT Topic 配置信息**，请将这些信息提供给机器人研发人员进行配置。

### 4.2 配置多大棚巡逻（新功能）

一台机器人可以负责多个大棚的巡逻任务：

1. 在机器人列表点击 **"详情"**
2. 切换到 **"🗺️ 多大棚巡逻"** 标签页
3. 点击 **"添加大棚"**，选择要巡逻的大棚
4. 配置：
   - **巡逻优先级**：数字越小越先执行，默认1
   - **巡逻间隔**：每隔多少分钟巡逻一次，默认60分钟
   - **是否启用**：可以临时暂停某个大棚的巡逻
5. 点击 **"添加"** 保存

重复以上步骤可添加多个大棚。

### 4.3 调整巡逻参数

在多大棚巡逻页面点击 **"巡逻参数"**：
- **巡逻速度**：机器人行进速度（m/s）
- **拍照间隔**：每隔几个点位拍一张照片
- **低电返回阈值**：电量低于此值自动返回充电
- **自动巡逻**：开启后按配置自动执行巡逻

### 4.4 删除机器人

在列表中点击 **"删除"**，确认后删除。

## 五、运营中心（仪表盘）

点击 **"运营中心"** 查看整体运营数据：

| 卡片 | 说明 |
|------|------|
| 大棚总数 | 当前活跃大棚数量 |
| 机器人总数 | 已注册机器人总数 |
| 在线设备 | 当前在线的机器人数量 |
| 进行中任务 | 正在执行的巡检任务数 |
| 今日数据 | 今天采集的遥测数据条数 |
| 今日图片 | 今天上传的图片张数 |

页面中间显示近6小时的温度、湿度、CO₂实时趋势折线图（本地时间显示）。

右侧显示当前各传感器最新数值。底部显示所有大棚的状态概览。

> ⚡ 顶部导航栏显示"MQTT实时"绿色指示灯，表示与机器人的实时连接正常。

---

## 六、数据中心

点击 **"数据中心"** 查看历史数据：

**筛选方式：**
1. 选择大棚（顶部下拉菜单）
2. 选择时间范围（1小时 / 6小时 / 12小时 / 1天 / 2天 / 7天）

**趋势图表**：显示温度、湿度、土壤湿度、CO₂、光照、电量的历史趋势，鼠标悬停查看具体数值（显示本地时间）。

**原始数据**：切换到"原始数据"标签，查看详细数据表格，支持翻页。

---

## 七、图片管理

点击 **"图片管理"** 管理机器人采集的照片：

### 7.1 上传图片

1. 左侧面板选择机器人（必选）
2. 选择网络类型（WiFi 立即上传 / 4G 标记缓存）
3. 拖拽图片到上传区域，或点击选择文件
4. 上传成功后图片出现在右侧

**支持格式**：JPG / PNG / GIF / WebP（最大20MB）

### 7.2 筛选图片

左侧选择大棚，右侧图片列表自动过滤。

### 7.3 删除图片

点击图片右下角的 🗑️ 图标，确认后删除。

---

## 八、系统配置

点击 **"系统配置"** 调整系统参数：

### MQTT 配置
修改 MQTT Broker 地址、端口、账号密码。**保存后需要重启服务才能生效**（联系运维人员执行）。

### 系统参数
- **告警阈值**：温度/湿度/CO₂超出阈值时顶部导航栏会出现告警提示
- **数据保留天数**：历史数据保留多少天
- **图片上传限制**：单张图片最大体积

---

## 九、告警提示

当环境数据超出阈值时，顶部导航栏的 🔔 图标会显示红色数字：

- 🌡️ **温度过高**：超过配置的最高温度阈值（默认35°C）
- 💧 **湿度过高**：超过配置的最高湿度阈值（默认90%）
- 🌫️ **CO₂超标**：超过配置的CO₂上限（默认1200ppm）

点击 🔔 查看告警详情，点击"清除全部"关闭告警提示。

## 十、常见问题

**Q：大屏上机器人位置不动？**
A：机器人需要通过 MQTT 实时上报位置数据，请确认机器人已上线并正常发送数据。

**Q：图表显示"等待数据..."？**
A：该大棚还没有机器人上报数据，请确认机器人已注册并正在上传。

**Q：新注册的机器人没有收到消息？**
A：注册后系统自动订阅，无需重启。若仍有问题，请联系运维人员检查 MQTT 连接状态。

**Q：顶部显示"连接中..."？**
A：WebSocket 连接正在建立，等待约3秒后自动连接，若长时间不连接请刷新页面。

**Q：图片上传一直失败？**
A：检查文件格式（JPG/PNG/WebP）和大小（小于20MB），确认选择了正确的机器人设备。
